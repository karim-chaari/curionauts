Privacy policy

Last updated: 11 October 2026

"Curionauts TV pipeline" is a private tool. I am its only user. It signs in to my own YouTube channels and my own TikTok account to upload the videos I make, and does nothing with anyone else's account.

YouTube API Services

The tool uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it does with YouTube: uploads my videos (always as private), sets their title, description, thumbnail, captions and playlist, and manages my channel's own private live broadcasts. It reads back only my own videos to check they were saved correctly.

What data it keeps

  • The sign-in tokens for my own accounts. They are kept in files on my own machines that only my user can read, never shared, sold or sent anywhere else.
  • The metadata of my own videos that the tool itself writes (titles, descriptions, thumbnails, captions).

It does not collect, read or store any data about viewers or about other people's channels. It sets no cookies and has no analytics.

Deleting the data, revoking access

Access can be revoked at any time at Google security settings (third-party access). When access is revoked, or on request, the stored tokens are deleted within 7 days; there is no other stored API data to delete. TikTok access can be removed in the TikTok app under Settings, Security, Manage app permissions.

Google API data

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
